# ZeroOS / ZeroCode

Sistema fictício usado nos computadores do jogo. ZeroTrace analisa registros,
ZeroVault consulta as evidências recuperadas, ZeroLink mostra a estação local.

`logo.png`: criado com a ferramenta integrada de geração de imagens.
Prompt: emblema original de sistema operacional em pixel art para ZeroCode,
chamado ZeroOS; zero oco fundido com barra diagonal de código, silhueta
assimétrica em degraus, pixels de circuito destacados, ciano, azul-petróleo
e magenta; transparência real; sem texto e sem símbolos de outros sistemas.

`trace.svg`, `vault.svg`, `link.svg`: ícones originais desenhados em uma grade
32 × 32 com `shape-rendering="crispEdges"`, escaláveis sem suavizar os pixels.
